# @deepseek-ai/dsh-client-ui-settings-ai-route

Settings → **AI Route**: sign in through the system browser (OAuth PKCE against `https://aiapi.hoj.kr`), then see the
account's allowance usage (5-hour and weekly windows in credits, with reset times; a window the plan does not limit is
hidden) and the model list the plan includes. Uncensored models carry a red shield; free models a "Free" tag.
